==== LOADSTRINGS (scripts externes chargés par faf) ====

1) Interface, chargée au démarrage (fonction 0) :
   loadstring + HttpGet sur
   https://raw.githubusercontent.com/csgo1compte-cloud/RayVoid/refs/heads/main/AirFlow

2) Module Fleet (fonction 0.42, qui référence aussi "readfile" et "Fleet.lua") :
   loadstring + HttpGet sur
   https://raw.githubusercontent.com/csgo1compte-cloud/RayVoid/refs/heads/main/Fleet

3) Rechargement automatique après téléportation (fonction 0.36.2, via queue_on_teleport).
   Cette chaîne figure telle quelle dans le script :
   loadstring(game:HttpGet("https://akkiwi.com/h"))()

Note : pour 1) et 2), le script ne contient pas la ligne complète sous forme de texte ;
les constantes "loadstring", "HttpGet" et l'adresse sont côte à côte dans la même fonction.
